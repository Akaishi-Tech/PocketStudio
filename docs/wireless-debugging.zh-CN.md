# 用一台 Android 设备无线调试另一台

[English](wireless-debugging.md) · 简体中文

两台设备接入同一个允许设备互访的 Wi‑Fi 网络。主机安装掌上 Studio 和 Android 开发环境插件，目标手机运行 Android 11 或更高版本。

1. 在目标手机的「开发者选项 → 无线调试」中启用无线调试，确认系统的网络授权。在此页面记下 IP 地址和**连接端口**。
2. 在目标手机点「使用配对码配对设备」。保持弹窗打开，记下六位配对码和弹窗中的**配对端口**。
3. 在主机打开「调试 → 无线配对」，输入目标 IP、配对端口和六位码。配对成功后，目标系统的已配对设备列表中会出现这台主机。
4. 在随后显示的连接窗口输入无线调试主页面的**连接端口**。下次可直接连接已配对的设备。切换网络或重启无线调试后，从目标设置重新读取端口。
5. 安装并启动目标应用的 debug APK，点「附加进程」选中其包名。在正在编辑的源码中选中可执行行，按 Ctrl+F8 设置断点，或在调试面板中指定完整类名和行号。操作目标应用触发该行后，可在主机查看调用栈及变量，按 F8 单步或 F9 继续。

配对密钥保存在主机应用私有目录。清除主机应用数据后需要重新配对。在目标的「已配对设备」中选择主机并移除，即可撤销授权。

## 双模拟器复核

准备两台独立且允许安装测试 APK 的 Android 模拟器。打开目标的六位码弹窗，在项目根目录运行下列命令。最后两个参数依次是目标的配对端口和连接端口，运行时从标准输入读取六位码。

```sh
tools/test/two-emulators.sh emulator-5580 emulator-5582 --wireless PAIR_PORT CONNECT_PORT
```

使用项目要求的 JDK、Gradle 缓存和 Android SDK，并将 `ANDROID_HOME` 指向已安装的 SDK。测试脚本通过开发机回环地址分别转发目标的两个端口，以连通模拟器各自的虚拟网络。配对和 TLS 连接均由主机模拟器上应用内的 ADB 组件完成。真机同网使用时可直接填写目标设置显示的地址和端口。

已通过两台 Android 16（API 36）、x86_64、4 KiB 内存页模拟器的端到端验证。验证内容包括配对密钥、APK 安装、Logcat、附加 ART 进程、行断点、局部变量、单步，以及恢复后目标应用的状态。重跑脚本会编译专用测试 Activity。此测试未覆盖真机 Wi‑Fi 网络、其他 CPU 架构或 16 KiB 页运行环境。

## 单模拟器复核本机调试

准备一台已连接 Wi-Fi 的测试模拟器，开启无线调试并保持「使用配对码配对设备」弹窗打开。把命令中的序列号替换为这台模拟器的序列号，按提示输入系统显示的六位码。

```sh
tools/test/two-emulators.sh emulator-5584 --local
```

脚本将 Studio、测试程序和可调试示例部署到同一台模拟器，验证自动发现端口、配对和密钥重连。测试脚本的 `--local` 参数也接受指定端口，便于单独验证传输。要验证应用界面，请在项目的「调试 → 本机调试」中点「去设置配对」，并通过通知回复系统显示的六位码。

在 Android 16（API 36、x86_64）模拟器上，已通过系统通知验证六位码配对、输入位数不足时重新回复，以及重新打开应用后自动发现端口并重连。传输测试也已在 4 KiB 内存页模拟器上覆盖安装和启动示例、读取 Logcat、命中源码断点、检查局部变量、单步、继续和分离。
